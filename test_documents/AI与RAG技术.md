# 人工智能与大语言模型

## 一、什么是大语言模型

大语言模型（Large Language Model，简称 LLM）是一种基于 Transformer 架构的深度学习模型，
通过在海量文本数据上进行预训练，学习语言的概率分布和语义结构。代表性模型包括
GPT 系列、Claude、DeepSeek、Llama、Qwen 等。

## 二、RAG 检索增强生成

RAG（Retrieval-Augmented Generation）是一种将外部知识库与大语言模型结合的技术方案。

核心流程分为三个阶段：
1. **索引阶段**：将文档解析、分块、向量化后存入向量数据库
2. **检索阶段**：用户提问后，通过向量相似度检索最相关的文档片段
3. **生成阶段**：将检索到的上下文与用户问题一同送入 LLM，生成带引用的回答

RAG 的优势：
- **知识可更新**：无需重新训练模型即可注入新知识
- **事实更准确**：回答基于检索到的真实资料，减少幻觉
- **可追溯性**：每个回答都能给出引用来源

## 三、Embedding 向量表示

Embedding 模型将自然语言文本映射到高维向量空间，使得语义相近的文本在向量空间中距离较近。

常用 Embedding 模型：
- **BGE (BAAI)**：智源研究院开源，中文效果优秀，支持多粒度检索
- **text-embedding-3**：OpenAI 出品，效果稳定
- **Cohere Embedding**：多语言支持好

相似度计算方式：
- 余弦相似度（Cosine Similarity）：最常用
- 内积（Inner Product）：配合归一化可等价于余弦
- 欧氏距离（L2 Distance）

## 四、向量数据库

向量数据库专门用于高效存储和检索向量数据：

| 数据库 | 特点 | 适用场景 |
|--------|------|---------|
| FAISS | Facebook 开源，CPU/GPU 均可，轻量 | 本地部署、单机小规模 |
| Milvus | 分布式、高性能 | 企业级大规模 |
| Pinecone | 全托管云服务 | 不想运维的团队 |
| Chroma | 轻量级、Python 原生 | 原型开发、教学演示 |
| Weaviate | 支持混合搜索 | 多模态应用 |

FAISS 的 IndexFlatIP 是最基础的索引类型，适合中小规模（百万级以内）向量的精确检索。

## 五、Prompt Engineering 提示词工程

好的提示词是 RAG 效果的关键：

- **System Prompt**：定义模型角色和行为边界
- **Context**：检索到的文档片段，需清晰标注来源
- **Instruction**：明确指令，如"优先参考资料内容"
- **Output Format**：指定输出格式，如 Markdown + 引用列表

## 六、RAG 优化方向

1. **文档分块策略**：按语义段落而非固定长度切分
2. **混合检索**：向量相似度 + BM25 关键词召回
3. **重排序（Rerank）**：对 Top-K 结果用 Cross-Encoder 精排
4. **查询改写**：对用户问题进行扩展或分解
5. **多轮对话记忆**：维护对话历史以支持连续提问
